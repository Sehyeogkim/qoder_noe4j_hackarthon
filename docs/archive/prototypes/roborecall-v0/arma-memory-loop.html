성공과 실패를 같은 Attempt에 기록
스키마 초안 · 단계별 데이터는 합성 예시


attempt_id · step_index
한 시도 아래에 여러 action과 관측을 연결.
매 action을 별개의 실패 경험으로 만들지 않음.


goal · criteria · instruction
원래 목표, 성공 기준, 실제 실행 지시.
무엇을 기준으로 평가했는지 함께 보존.


status · outcome · reason
상태는 running / completed.
종료 결과는 success / failure / unknown.


evidence_refs · latest_observation_ref
프레임·영상·실행 로그 참조와 관측 사실.
결과와 근거 저장 후 completed로 전환.


judgment_source · hypothesis
환경 판정과 시각 추론을 구분.
원인 가설은 미확인 상태로 별도 기록.


context · previous_attempt_id
검색용 상황·조건과 이전 시도 연결.
이번 결과 조회는 정확한 ID로 수행.




완료 확인도 Memory에서. 행동 agent는 이번 attempt의 상태를 조회합니다. 진행 중이면 현재 관측과 상태로 다음 행동을 판단하고, 완료되면 저장된 결과를 읽습니다. RGB를 직접 해석하려면 이미지 입력을 지원하는 모델이 필요합니다.
